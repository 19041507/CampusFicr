# CampusFicr
Campus Fácil 360 é uma plataforma web para faculdades que integra mapa inteligente com QR Code, achados e perdidos e feedback anônimo das aulas. O sistema ajuda alunos a se localizarem no campus, recuperarem objetos perdidos e avaliarem aulas de forma rápida, enquanto professores e adms recebem dados úteis para melhorar a experiência acadêmica.
